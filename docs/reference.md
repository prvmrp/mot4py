# Development reference

All the documentation for the software development is reported in this
section.

## MOTlang handling

### Language parsing

Language parsing is done in the parser module, according to a lark
grammar which is defined in the Parser class. The intermediate code is
generated by the Interpreter class.

::: mot4py.parser
    options:
        show_source: false
        show_root_heading: true
        heading_level: 4
        show_root_full_path: false
        relative_crossrefs: true

### Intermediate code functions

The intermediate code is handled by the functions module. 

::: mot4py.functions
    options:
        show_source: false
        show_root_heading: true
        heading_level: 4
        show_root_full_path: false
        relative_crossrefs: true
